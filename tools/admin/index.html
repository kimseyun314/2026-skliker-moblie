③ 선수별 QR 코드

QR에는 모바일 주소?p=QR ID가 들어가요. QR ID는 선수를 추가할 때 한 번 만들어지고 바뀌지 않아서, 정보를 수정해도 이미 인쇄한 QR은 그대로 쓸 수 있어요. 선수를 삭제하면 그 QR은 더 이상 열리지 않아요.

방법 A. 파일로 올리기

배포용 파일을 받아서 GitHub 저장소의 data/players.csv(선수)와 data/meta.json(행사 설정)에 덮어써요.

방법 B. GitHub에 바로 저장

개인 토큰으로 이 화면에서 바로 커밋해요. 1~2분 뒤 사이트에 반영돼요.

구글폼 응답 붙여넣기

구글폼 응답 시트에서 제목 행을 포함해 전체를 복사(Ctrl+C)해서 붙여넣거나, CSV로 내려받은 내용을 붙여넣으세요. 같은 사람(실명 → 닉네임 순으로 찾아요)은 원래 QR에 그대로 업데이트되고, 새 사람은 미리 만든 빈 QR ID에 순서대로 붙어요. 가져오면 기준선(참가자 중앙값) 재계산 → 유형 분석 → 팀 자동 배정까지 한 번에 해요.
